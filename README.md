## 🛠️ How to Run Locally

### Option 1: Direct Browser (Zero Dependencies)
Double-click `index.html` or open it directly in any browser.

### Option 2: Node.js Web Server
```bash
node server.js
```
Opens at `http://localhost:3000`.

### Option 3: Java Web Server (Zero External Dependencies)
```bash
java PortfolioServer.java
```
or
```bash
javac PortfolioServer.java
java PortfolioServer
```
Opens at `http://localhost:8080`.

### Option 4: Quick Launch (Windows)
Double-click `run.bat`.
